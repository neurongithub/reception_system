## [feature user management]
System user management

## Overview
- View the list of system users
- Create new users
- Edit and delete users
- Has three different authorizations: Admin, Operator, Regular User
- Initial launch page
- Search for username
- Display system users based on filters: (new to old), (old to new), (and role)
- Show the user you are logged in with
- Display system user statistics
